## 🚀 Key Features

* **Declarative Rulesets**: Leverages modern Manifest V3 standards to perform safe, high-speed request filtering.
* **Anti-Tracking Protections**: Eradicates analytic script triggers.
* **Minimal Memory Overhead**: Runs fully in-memory with zero background CPU overhead.
